# Feeling Zone - Added Features

- Search feelings by text or name
- Sort by newest, oldest, or most liked
- Favorites/bookmarks saved in the browser
- Copy a feeling to clipboard
- Share with the device share sheet or WhatsApp fallback
- Download individual feelings as `.txt`
- Like protection per browser (prevents repeated likes from the same browser)
- Auto-save writing draft to browser storage
- Clear draft button
- Admin statistics: total posts, total likes, your posts, favorites
- Edited-post indicator
- Random feeling picker
- Read-time estimate
- Admin authentication, edit and delete controls
- Firebase Realtime Database integration
- Private browser-side chat session for the support chat
- Social-media downloader backend endpoint (requires RAPIDAPI_KEY)
- Firebase database rules template included in `database.rules.json`
